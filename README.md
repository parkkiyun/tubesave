# TubeSave Desktop

macOS와 Windows에서 실행하는 Electron 기반 영상 다운로드 앱입니다. 본인 소유 또는 다운로드 허가를 받은 콘텐츠에 사용하세요. 회원 전용 콘텐츠는 본인 계정에 실제 시청 권한이 있는 경우에만 지원하며 접근 제한이나 DRM을 우회하지 않습니다.

## 저장소 준비 상태

TubeSave Desktop 2.1 소스와 배포 설정을 가져오는 중입니다. 아직 이 저장소에 정식 설치본 또는 검증된 자동 업데이트 릴리스는 공개되지 않았습니다.

GitHub Releases 배포, 코드 서명, Apple 공증, 운영체제별 설치·업데이트 실기기 시험을 통과한 뒤 정식 릴리스를 공개합니다. 인증서·비밀번호·쿠키·토큰은 커밋하지 마세요.
