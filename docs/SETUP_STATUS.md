# TubeSave 배포 연결 현황

2026-09-21. 이 브랜치는 아직 전체 앱이 아니며 병합/배포하면 안 됩니다.

## 실제 업로드

핵심 모듈, renderer JavaScript/CSS, 두 운영체제 온라인 설치 스크립트, 엔진 번들링, 코드 서명·공증 및 설치본 빌드 스크립트, 전체 Node 테스트 파일을 추가했습니다. release/config.json은 parkkiyun/tubesave에 연결되어 있습니다.

## 실제 GitHub Actions 실행

첫 배포 준비 검사: https://github.com/parkkiyun/tubesave/actions/runs/35564798486

- 업데이트 상태 전이 단위 테스트 및 JavaScript 문법 검사: 성공.
- npm 잠금 파일 생성 및 npm ci --ignore-scripts: 성공. 실제 Electron 실행 파일 설치나 실행을 검증한 것은 아닙니다.
- 생성된 두 package-lock.json을 별도 검토 브랜치에서 가져왔습니다. 다음 실행에서는 잠금 파일 구조/배포 출처/정확한 의존성 버전을 검사합니다.
- 서명 환경 검사: Mac 6개 설정, Windows 2개 설정과 배포자 이름이 이 작업에 제공되지 않아 실패했습니다. 비밀값을 출력하거나 변경하지 않았습니다.
- 필수 소스 완전성 검사: 누락 파일로 실패. 정확한 최신 목록은 Actions의 source-completeness 결과를 확인하세요.

## 남은 차단

app/main.cjs와 app/ui/index.html 업로드 요청이 도구 안전성 확인 단계에서 차단됐습니다. 해당 파일을 다른 도구·경로·인코딩으로 우회 업로드하지 않았습니다. 도구 응답에는 상세 원인이 없습니다. 아이콘 PNG/ICO/ICNS 및 일부 보조 문서 업로드도 아직 남아 있습니다.

따라서 전체 업로드, 앱 빌드, 실제 자동 업데이트 완료 상태가 아닙니다. 테스트 일부 성공을 전체 앱 설치 성공으로 간주하지 않습니다. 최신 워크플로는 독립적인 모듈 테스트, 필수 소스 검사, 잠금 의존성 설치, 서명 설정 존재 검사를 분리하여 실행합니다.

## 정식 배포 조건

전체 소스·자산 업로드 → 잠금 의존성 확인 → Developer ID/Windows 코드 서명 설정 → 각 OS 설치본 생성 → 첫 정식 설치 → 더 높은 안정 버전으로 실제 자동 업데이트 교체 검증이 필요합니다.

기존 bootstrap 설치본에는 공식 updater feed가 없습니다. 서명 검증을 끄거나 미완성 앱을 정식 릴리스로 공개하지 않았습니다. 현재 main 병합 및 릴리스 공개는 하지 않았습니다.
