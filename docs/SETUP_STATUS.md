# TubeSave 배포 연결 현황

2026-09-21. 이 브랜치는 아직 전체 앱이 아니며 병합/배포하면 안 됩니다.

## 이번에 보존한 변경

기존 핵심 모듈에 더해 renderer JavaScript, 설치본 빌드 설정, 엔진 번들링 스크립트, Mac 서명·공증 스크립트, updater 단위 테스트를 추가했습니다. `release/config.json`은 parkkiyun/tubesave에 연결되어 있습니다.

`TubeSave deployment readiness` 워크플로를 추가했습니다. 작업 브랜치 push 시 (1) updater 상태 전이 테스트, (2) 필수 파일 누락 검사, (3) npm 잠금 파일 생성·설치 검증, (4) 서명 설정의 존재 여부만 점검합니다. 비밀값은 출력하지 않습니다. 생성한 잠금 파일은 별도 검토 브랜치에만 보존하며 main에 자동 병합하거나 설치본을 공개하지 않습니다.

## 남은 차단

명시적인 전체 업로드 요청에 따라 재시도했지만 app/main.cjs 요청이 도구 안전성 확인 단계에서 차단되었습니다. 별도의 app/ui/index.html 업로드 요청도 같은 단계에서 차단되었습니다. 해당 두 파일을 다른 경로·인코딩·도구로 우회 업로드하지 않았습니다. 정확한 차단 원인은 도구 응답에 제공되지 않았습니다.

따라서 전체 업로드·앱 빌드·자동 업데이트가 성공했다고 볼 수 없습니다. 이 브랜치의 실제 누락 파일은 `node scripts/check-source.cjs` 및 Actions 실행 로그를 기준으로 확인하세요. 일부 단위 테스트 성공은 앱 실행이나 실기기 자동 교체 성공과 다릅니다.

## 정식 배포 조건

필수 소스와 자산 업로드 완료 → 검토된 두 npm lockfile → Developer ID/Windows 배포 서명 설정 → Mac arm64·Intel 및 Windows x64 실제 설치본 → 첫 정식 설치 → 더 높은 버전으로 실제 업데이트 검증이 필요합니다.

기존 온라인 bootstrap 설치본의 updater는 비활성입니다. 서명 검증을 끄거나 미완성 앱을 정식 릴리스처럼 게시하지 않았습니다. 기존 파일·사용자 쿠키·인증서를 공개하지 않았습니다.
