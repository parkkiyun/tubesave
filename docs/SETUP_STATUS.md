# GitHub 초기 연결 및 소스 가져오기 상태

## 실제 확인한 내용

- `parkkiyun/tubesave`는 공개 저장소이며 GitHub 앱 설치와 실제 파일 쓰기가 성공했습니다.
- 기본 브랜치 `main`에는 초기 README가 있습니다.
- `setup/tubesave-desktop-2.1`는 초기 가져오기를 보존하는 작업 브랜치입니다. **아직 실행 가능한 전체 앱이 아닙니다.**
- 이번에 업로드가 성공한 다운로드·쿠키 연결·프로세스·업데이트 모듈과 패키지 설정을 이 브랜치에 보존합니다.
- `release/config.json`은 `parkkiyun/tubesave`를 가리킵니다. Windows 인증서의 배포자 이름은 미입력입니다.

## 중단 지점

`app/main.cjs`를 업로드하는 요청에서 OpenAI 연결 도구가 두 차례 “요청의 보안 상태를 결정하지 못해 ... 차단되었습니다”를 반환했습니다. 이 파일을 다른 API나 인코딩으로 우회 전송하지 않았습니다. 메인 파일·UI·설치기·나머지 테스트 등 전체 파일 가져오기가 남아 있습니다. GitHub의 403 권한 오류가 재발한 것으로 보고하지 않습니다.

## 검증과 배포

제작 환경의 **전체 작업 사본**에서 Node 테스트 141개가 통과했습니다. 이는 이 **불완전한 원격 브랜치**가 테스트를 통과했다는 뜻이 아닙니다. npm 레지스트리 DNS 연결 실패로 두 package-lock.json의 생성·의존성 설치 확인도 남아 있습니다.

검증 워크플로는 초안 PR에서 테스트를 실행하지 않고, 일반 실행에서는 필수 소스가 없으면 실패하도록 했습니다. 전체 소스를 가져온 뒤 잠금 파일을 생성·검토하고, 코드 서명·Apple 공증·실기기 설치 및 자동 업데이트 시험을 완료해야 합니다. **아직 main 병합, 정식 설치본 빌드, 릴리스 공개를 하지 않았습니다.**

쿠키·개인키·인증서·토큰은 이 저장소와 채팅에 올리지 않습니다. 서명 설정은 `tubesave-release`의 Secrets/Variables에 관리합니다. 현재 도구에서는 해당 환경·비밀값 등록 여부를 확인하지 않았습니다.
