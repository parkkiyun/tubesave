# 소스 가져오기 현황

이전 부분 업로드 상태는 해소됐습니다. 메인 프로세스, 화면 HTML/JS/CSS, 플랫폼 아이콘, 다운로드와 로그인 모듈, 업데이트 모듈, Mac/Windows 설치기, 빌드/서명 스크립트와 두 잠금 파일을 포함합니다.

아이콘은 기존 TubeSave의 기하학적 마크를 재현하는 scripts/generate-icons.cjs로 PNG/ICO/ICNS를 생성했고 실제 생성된 바이너리를 커밋했습니다. 임의로 꾸민 Git 해시나 npm 잠금 파일을 사용하지 않습니다.

과거 작업 사본의 시점별 로그/스크린샷을 소스 검증의 근거로 재사용하지 않습니다. 최신 CI와 docs/SETUP_STATUS.md를 확인하세요.
