# TubeSave 시작하기

엔진 포함 테스트 설치본: GitHub 저장소 → Actions → 성공한 `Build and test desktop preview installers` 실행 → Artifacts에서 본인 운영체제를 고릅니다. 압축 안의 dist-preview 폴더에 Mac DMG/ZIP 또는 Windows Setup EXE가 있습니다.

Preview는 정식 개발자 서명·공증 배포본이 아닙니다. 운영체제의 보안 경고가 나타날 수 있으며, 조직의 보안 정책을 해제하지 마세요. Preview에는 정식 앱 자동 업데이트가 활성화되어 있지 않습니다.

기존 온라인 설치기를 사용할 때는 ZIP을 전부 압축 해제한 뒤 Mac의 install_mac.command 또는 Windows의 install_windows.bat를 실행합니다. 설치 중 인터넷이 필요합니다.

앱에서 영상 링크를 입력하고 화질/형식을 선택하여 저장합니다. 회원 영상은 브라우저에서 본인 계정으로 재생 가능한지 확인하고 로그인 연결을 선택합니다. 쿠키 파일을 채팅이나 GitHub에 올리지 마세요.
